# Military Silhouettes Asset Library

Comprehensive, curated physical library of **121 authentic military silhouettes** across 8 combat domains, engineered for wargame counter design, tactical maps, briefing slides, and defense applications.

Available in both crisp, infinitely-scalable vector **`SVG`** and high-resolution **1024×512 transparent `PNG`**.

## 🎯 Dual Delivery: Vector & Transparent Raster

Each asset is provided in two identical formats:
1. **`.svg` (Scalable Vector Graphics)**:
   - Clean, lightweight SVG path code with `viewBox="0 0 512 256"` (or domain standard).
   - Can be styled with any CSS fill color (`#1e293b`, `#ffffff`, olive drab, woodland camo, etc.).
   - Embeds losslessly into web apps, Adobe Illustrator, Inkscape, Figma, or LaTeX documents.

2. **`.png` (High-Resolution Transparent Raster)**:
   - 1024×512 pixels with subpixel antialiasing and 100% transparent alpha channel.
   - Ready for drag-and-drop into TDX Counter Designer, PowerPoint, VASSAL, Tabletop Simulator, or Roll20.

---

## 🚀 In-App Integration in TDX Counter Designer

In **Tactical Symbology & Counter Studio** (`token-editor.html`):
1. Click **`+ Silhouette`** in the canvas top bar or in the **Decals Inspector**.
2. Filter by branch tab (Armor, Tactical, Aviation, Helis, Drones, Naval, Infantry, Fortifications) or type keywords in the live search bar.
3. Click **`+ Add to Token`** to immediately insert the silhouette as a centered, scalable, rotatable decal layer on your counter.
4. Scale, rotate, adjust opacity, blend modes, or die-cut boundary clipping with standard transform controls.
